# MCP安检 — MCP服务器安全扫描工具

一键检测你的 AI 编程工具的 MCP 安全配置。支持 Claude Desktop、Cursor、VS Code、Windsurf、OpenClaw 等所有主流 AI 客户端。

## 快速开始

```bash
npx mcp-scan
```

## 能扫什么

- 🔴 **命令注入** — Shell 命令参数中是否拼接了用户输入
- 🔴 **硬编码密钥** — 环境变量中是否泄露了 API Key/Token
- 🔴 **通用 Shell 执行** — 是否用 bash/sh 作为 MCP 命令
- 🟠 **路径遍历** — 文件访问是否限制了目录范围
- 🟠 **无认证远程服务** — HTTP MCP 服务器是否缺少认证
- 🟠 **HTTP 明文传输** — 远程服务是否用了不安全的 HTTP
- 🟠 **SSRF 风险** — curl/wget 是否限制了内网访问
- 🟡 **环境变量泄露** — 是否传递了大量系统环境变量
- 🟡 **已禁用配置残留** — disabled 的服务器是否没清理
- 🟡 **包管理器风险** — npm/pip 是否有供应链攻击风险
- 🔵 **缺少描述文档** — 是否缺少安全审计信息
- ⚪ **通信方式评估** — 传输方式的安全性评估

## 支持的客户端

| 客户端 | 配置文件路径 |
|--------|-------------|
| Claude Desktop | `~/.claude/claude_desktop_config.json` |
| Claude Code | `~/.claude.json` |
| Cursor | `~/.cursor/mcp.json` |
| VS Code | `~/.vscode/mcp.json` |
| Windsurf | `~/.windsurf/mcp.json` |
| OpenClaw/Clawd | `~/.clawd/mcp.json` |


## 安装

```bash
# 全局安装
npm install -g mcp-scan

# 或直接用 npx（免安装）
npx mcp-scan
```

## 最低要求

- Node.js >= 16.0.0

## 安全评分

| 评分 | 等级 | 含义 |
|------|------|------|
| 130-150 | A | 安全 — 配置合理 |
| 100-129 | B | 基本安全 — 有小问题 |
| 70-99 | C | 需要改进 — 存在中等风险 |
| 40-69 | D | 存在风险 — 需要立即修复 |
| 0-39 | F | 高危 — 存在严重漏洞 |
